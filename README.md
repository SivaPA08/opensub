# OpenSub

OpenSub is an open-source desktop application for Auto generating subtitles, editing, and styling subtitles with a visual editor.

<img width="1892" height="965" alt="image" src="https://github.com/user-attachments/assets/c9d2fb5d-8525-451a-8895-0372a651e4ea" />



## Features

- Auto Subtitle creation and editing
- Visual timeline editor
- Custom subtitle styling
- Local processing
- Cross-platform support (Windows, Linux, macOS)

## Installation

### Download Prebuilt Binaries

Download the latest installer or package from GitHub Releases or SourceForge.

### Build from Source

```bash
git clone https://github.com/SivaPA08/opensub.git
cd opensub

cargo tauri build
```

## Development

```bash
cargo tauri dev
```
