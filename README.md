# OpenSub

OpenSub is an open-source desktop application for generating, editing, and styling subtitles with a visual editor.

## Features

- Subtitle creation and editing
- Visual timeline editor
- Custom subtitle styling
- Local processing
- Cross-platform support (Windows, Linux, macOS)

## Download

### GitHub Releases

Download the latest release from:

https://github.com/SivaPA08/opensub/releases

### SourceForge

## Installation

### Download Prebuilt Binaries

Download the latest installer or package from GitHub Releases or SourceForge.

### Build from Source

```bash
git clone https://github.com/SivaPA08/opensub.git
cd opensub

cargo tauri build
```

## Development

```bash
cargo tauri dev
```
